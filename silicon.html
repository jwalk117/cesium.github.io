Your computer.

Compatibility is a goal to work toward, not a claim that everything already works.

The idea

A useful operating system needs to work with the devices and workflows people already have. Cesium's direction is to improve compatibility across hardware, applications, and common file formats wherever practical.

Be clear about what's ready

Compatibility takes time, testing, and a lot of hardware-specific work. Support varies by component and development stage. Check the project repository for the most accurate picture of what currently builds and runs.

Help test

Testing on different machines is valuable. If you find a bug or have hardware information to share, use the repository's issue tracker and include the device, relevant logs, and steps to reproduce the problem.
