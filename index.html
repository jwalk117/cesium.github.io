What is Cesium?

Cesium is an independent operating system project focused on building a new foundation for computing.

Developed from the ground up, Cesium aims to explore the possibilities of operating system architecture, kernel development, and system customization.

The goal is to create an adaptable operating system with a strong emphasis on compatibility and modularity.
