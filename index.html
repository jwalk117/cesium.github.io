THE PROJECT

A system built to work.

Operating systems shouldn't take time to set up compatibility or have a need to install tools for certain apps. Cesium aims to solve this problem by having the kernel built around being compatible with Linux, Windows, and MacOS.

Compatibility

Make it easier to use the hardware, software, and files people already rely on.

Modularity

Keep the system adaptable, with components that can evolve independently.

Security

Give people meaningful choices about how their system works and feels, which is especially necessary today.

MORE FROM ATOMIC

Atomic's goal is to create not just the ideal OS, but ideal, secure services and applications as well. As additional tools take shape, they will live alongside Cesium OS under Atomic.
